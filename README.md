# VARIUS

PWA LegalTech construida con Next.js 15 y React 19. Incluye el shell de producto para ciudadano, marketplace de abogados y asistente jurídico con aviso de orientación.

## Ejecutar

```bash
npm install
npm run dev
```

## Próximas capas

- API NestJS organizada por dominios y Prisma/PostgreSQL.
- Auth JWT/OAuth, perfiles y reservas.
- OpenAI vía backend, auditoría y moderación.
